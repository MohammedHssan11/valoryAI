# 08. Truth Layer & Governance Framework

This document outlines the Truth Layer, the governance model that maintains mathematical accuracy and prevents hallucinations in natural language outputs.

---

## 1. Locked Governance Rule
The platform enforces a strict separation of concerns between computational logic and natural language generation, summarized in the following rule:

```
Planner decides.
  │
  ├── Intent Engine resolves intent, Planner schedules Tools.
  ▼
Executor executes.
  │
  ├── Secure, tenant-scoped Tool execution; zero database access for LLM.
  ▼
Composer computes.
  │
  ├── Calculates all averages, ranges, deltas, and stats in Python code.
  ▼
Memory remembers.
  │
  ├── Manages chat transcripts, workspaces, properties, and scenario states.
  ▼
LLM narrates.
  │
  └── Summarizes or repeats composed facts exactly; zero reasoning or math.
```

The Language Model (LLM) is not an authority layer. It has no access to the database or raw modeling pipelines. It receives a bounded projection of data only after computational steps are completed. Its output is treated as candidate text until grounding rules accept it.

---

## 2. Governance Boundaries & Narration Contracts
* **Source Document:** [NARRATION_CONTRACT_ARCHITECTURE.md](file:///c:/Users/mh978/Downloads/mobile%20computing%20project/docs/NARRATION_CONTRACT_ARCHITECTURE.md)
* **Goal:** Binds natural language output to a strict subset of facts generated by the Tool Layer (Tools 1-8).
* **Narrative Allowances:**
  1. Restate upstream facts exactly.
  2. Describe evidence limitations and disclosures.
  3. Summarize upstream evidence without changing its meaning.
  4. Reference citation tokens exactly.
  5. State that evidence is sparse, insufficient, or unavailable.
* **Prohibited Behaviors:**
  1. Creating new facts, values, calculations, comparison metrics, or recommendations.
  2. Synthesizing or fabricating missing comparables.
  3. Converting sparse or low-confidence evidence into confident claims.
  4. Continuing execution after authentication or authorization checks fail.

---

## 3. Arithmetic Offloading Rule
Under this rule, the LLM is forbidden from executing any mathematical or arithmetic calculations (averages, percentage changes, valuations).
* **Rationale:** Language models cannot guarantee absolute mathematical precision and frequently make errors when calculating differences, averages, or value ranges.
* **Implementation:** The Response Composer performs all required calculations (e.g., comparing Property A to Property B, calculating size differences, or computing average rental rates) natively in Python. The computed outputs are injected into the prompt context for the LLM to narrate.
* **Prohibited Prompt Keywords:** System instructions explicitly restrict model generation from using terms like "predict", "calculate", or "extrapolate".

---

## 4. Citation & Grounding Enforcement
Every fact narrated by the LLM must map to a verifiable citation.
* **Citation Wrapper Syntax:**
  ```text
  [citation:<exact-received-id>]
  ```
* **Grounding Requirements:**
  - Every numerical value returned by the LLM must match an upstream value.
  - Every citation token must match an active `valuation_id`, `tool_event_id`, or `comparable_id` record.
  - Rejection of candidate text is required if these checks fail.
* **Fail-Closed Fallback:** If grounding check failures occur, the system suppresses the generated text and defaults to the deterministic JSON payload (`DETERMINISTIC_FALLBACK`), ensuring client applications still receive verified mathematical outputs.

---

## 5. Audit Trails & Persistence Design
All transactions and system outputs are persisted to enforce governance and traceability:
* **Tool Events (`tool_events`):** Logs every tool request, input parameters, and output payload.
* **Decision History (`decision_history`):** Audits active/shadow predictions, coordinates resolution accuracy, and confidence scores.
* **Valuation Snapshots (`valuation_snapshots`):** Stores the raw request schema, response stats, and explainability metrics for every valuation.
